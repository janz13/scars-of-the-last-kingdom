Game title:
Scars of the Last Kingdom

Platform:
Build this in Replit as a React + Vite web app. It should be mobile-first and ready to later wrap into Android using Capacitor.

Important:
Do not hardcode everything into one component. Build a scalable story engine that can support hundreds or thousands of story nodes, many routes, many character paths, and many endings.

Core story:
The world is set in a near dystopian future. Food, water, medicine, weapons, and trust are scarce. Civilization has collapsed after a city-wide blackout. The player wakes up in an abandoned underground metro station with fragmented memories and a strange mark on their wrist. The mark reacts to old relic machines and attracts dangerous enemies.

Story engine:
Create story nodes as data objects, not hardcoded UI.

Each node should support:
- id
- chapter
- title
- location
- image
- speaker
- text
- dialogue
- effectsOnEnter
- choices
- ending data if the node is an ending

Each choice should support:
- text
- nextNode
- effects
- requirements
- required flags
- blocked flags
- required background
- required class
- companion trust requirements
- faction reputation requirements
- ending trigger
- hidden or locked state

Example story node format:

{
  id: "chapter1_ruined_station",
  chapter: "Chapter 1",
  title: "The Ruined Station",
  location: "Old Metro Line 9",
  image: "/images/backgrounds/ruined_metro_station.png",
  speaker: "Narrator",
  text: "The air tastes like rust and old blood. Somewhere in the dark, something drags metal across the floor.",
  effectsOnEnter: {
    hunger: -1,
    morale: -1
  },
  choices: [
    {
      text: "Search the broken vending machines.",
      nextNode: "station_vending_search",
      effects: {
        scrap: 2,
        hunger: -1
      }
    },
    {
      text: "Call out to see if anyone is alive.",
      nextNode: "station_survivor_encounter",
      requirements: {
        charisma: 5
      },
      effects: {
        trust: 1
      }
    },
    {
      text: "Move silently through the tunnel.",
      nextNode: "station_shadow_path",
      requirements: {
        agility: 6
      },
      effects: {
        morale: -1
      }
    }
  ]
}
